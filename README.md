A newspaper front page that sums up the world news of Monday 23 November 2026 in one image. It leads with the collapse of the COP31 climate talks in Antalya, then covers the Kyiv drone strike, the Russian cargo ship ablaze off Finland, and the Indonesia factory fire, each with a small symbolic illustration drawn purely from PIL shapes. A bottom ticker carries the day's other headlines, from South Sudan to the 2035 Women's World Cup.

The image is generated deterministically by `draw_news.py` (PIL only, no randomness, no network) and copied into place by the stdlib-only `main.py`.

## Run it

python3 main.py
